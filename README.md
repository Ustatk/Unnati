# Features of Unnati
## Women-Centric Service Discovery 
 — Find relevant government schemes and services across welfare, health, education, livelihood, finance, safety, and rights.
## AI-Powered Chatbot 
 — Natural-language assistance for scheme discovery and service navigation.
## Eligibility Checker 
 — Assess preliminary eligibility using user-provided details and scheme criteria.
## Personalized Recommendations 
 — Recommend relevant services based on needs, circumstances, and location.
## Interoperability Middleware 
 — FastAPI-based gateway for routing, authentication, and cross-system communication.
## Data Normalization 
 — Map different source formats into a common data model.
## Unified Dashboard 
 — View recommended services and application/status information in one place.
## Multilingual & Accessible UI 
 — Simple, user-friendly access for diverse users.
## Security & Access Control 
 — Consent-aware access, RBAC, and audit logging.
